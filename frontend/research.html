Selected Publications & Whitepapers

Peer-reviewed reports, architecture whitepapers, and academic preprints.

Agricultural AI · 2026 DOI: 10.luminary/agroscan-vit-2026

Edge-Optimized Vision Transformers for Real-Time Plant Pathogen Identification

Authors: AR. Abhinav Ranjan, Luminary Research Group

This paper demonstrates how weight quantization and layer-pruning techniques reduce memory consumption of Vision Transformers by 74%, permitting direct 150ms inferencing in consumer smartphone browsers without cloud telemetry requirements.

Cloud Infrastructure · 2025 DOI: 10.luminary/static-resilience-2025

Architectural Resilience in Static Decentralized Web Applications

Author: AR. Abhinav Ranjan

Explores eliminating third-party npm dependency vulnerability trees by utilizing strictly vanilla ECMAScript, pure CSS layout tokens, and pre-indexed fuzzy search indexes for high-uptime mission-critical portals.
