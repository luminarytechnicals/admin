Accessibility Statement

Last updated: September 17, 2026

Commitment to Universal Accessibility (WCAG 2.1 AA)

Luminary Technicals is committed to ensuring digital accessibility for all users, including individuals with visual, motor, auditory, or cognitive disabilities. Our interfaces are tested against W3C Web Content Accessibility Guidelines (WCAG 2.1 AA).

Accessibility Features Implemented

  • Keyboard Navigation: All navigation menus, search overlays, and interactive modals can be traversed entirely via Tab, Shift+Tab, Arrow keys, and Escape.
  • Skip-to-Content: A visible skip link allows screen readers and keyboard users to bypass top navigation.
  • Color Contrast & Typography: High-contrast foreground elements with scalable rem/em units.
  • Semantic HTML5: Native landmarks (main, nav, section, article, footer) with minimal ARIA overrides.
  • Reduced Motion Support: Respects `prefers-reduced-motion` browser settings, muting heavy transitions and canvas simulations.
