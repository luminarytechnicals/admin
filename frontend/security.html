Security Policy

Last updated: September 17, 2026

Zero-Trust Architecture

Luminary Technicals builds and deploys systems under defense-in-depth and zero-trust principles. All public-facing web applications are constructed without runtime dependency trees, eliminating npm supply-chain compromise vectors.

Security Headers & Hardening

  • Content Security Policy (CSP): Strict default-src isolation prohibiting unauthorized cross-origin execution.
  • X-Content-Type-Options: nosniff to prevent MIME confusion.
  • Referrer-Policy: strict-origin-when-cross-origin.
  • Zero Secret Exposure: No private database keys, administrative tokens, or private credentials exist in frontend code.

Vulnerability Disclosure Program

Security researchers discovering vulnerabilities are requested to notify us responsibly. Send complete reproduction details and scope analysis to:

luminarytechnicals@gmail.com

We acknowledge receipt within 48 hours and coordinate prompt remediation.
