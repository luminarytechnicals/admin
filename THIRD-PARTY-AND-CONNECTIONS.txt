 10.  CONFIG-GATED SERVICES — NOTES
================================================================================

The following services are coded into main.js but ONLY activate if their
respective configuration keys are set in config.js:

  1. Google Analytics / Tag Manager
     Activates when: CONFIG.analytics.enabled = true
                 AND CONFIG.analytics.googleAnalyticsId is set
     Loads: https://www.googletagmanager.com/gtag/js?id=<ID>

  2. Microsoft Clarity
     Activates when: CONFIG.analytics.enabled = true
                 AND CONFIG.analytics.clarityId is set
     Loads: https://www.clarity.ms/tag/<ID>

  3. Google AdSense
     Activates when: CONFIG.ads.enabled = true
                 AND CONFIG.ads.clientId is set
     Loads: https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js

  ⚠️  CSP NOTE: The current Content-Security-Policy in HTML <meta> tags
      does NOT whitelist these 3rd party script/connect domains. If you
      enable analytics or ads in config, you MUST also update the CSP
      meta tag across all 35 pages to include:
        script-src: googletagmanager.com, clarity.ms, pagead2.googlesyndication.com
        connect-src: google-analytics.com, clarity.ms
